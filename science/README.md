# Scientific guide

The question is how much control that acts on individual spins is needed to prepare a collective probe while independent noise continues to act. Collective processing can regenerate phase sensitivity inside a spin sector. It cannot replenish the spin-sector moment that the allowed collective controls preserve.

The account follows that distinction from the model to an optimal resource order:
